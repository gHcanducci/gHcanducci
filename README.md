## 🎯 Sobre mim

Estudante de **Sistemas de Informação** (6º semestre) com foco em **desenvolvimento back-end e full stack .NET**. Construo sistemas web e APIs com C#, ASP.NET, Entity Framework e SQL Server, e tenho como base de trabalho a prática: cada projeto abaixo saiu do papel e está no GitHub.

Fora do código, sou **instrutor de boxe**. Ensinar turmas e alunos particulares me deu didática, comunicação e hábito de trabalhar em equipe, e levo isso para o desenvolvimento.

**Procuro:** oportunidade inicial em Tecnologia, em Desenvolvimento de Software (back-end e full stack .NET), em regime **remoto (todo o Brasil)** ou **presencial/híbrido no Oeste Paulista**.
